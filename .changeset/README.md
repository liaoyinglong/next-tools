# Changesets

Hello and welcome! This folder has been automatically generated by `@changesets/cli`, a build tool that works
with multi-package repos, or single-package repos to help you version and publish your code. You can
find the full documentation for it [in the repository](https://github.com/changesets/changesets).

## Usage

To add a changeset, run `pnpm changeset` in the root of the repository. This will prompt you to select which
packages have changed and what type of change (major, minor, patch) was made.

To version packages, run `pnpm changeset version`. This will consume all changesets and update package versions
and changelogs accordingly.

To publish packages, run `pnpm publish -r`.
