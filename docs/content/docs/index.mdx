# Next Tools

一套面向 React / Next.js 应用的工具集合，包含运行时工具库、CLI 代码生成器和 Babel 编译优化插件。

## 功能特性

### Tools

运行时工具库（`@dune2/tools`），提供了一系列实用的开发工具和组件。

#### 模块一览

- **factory**：`createStateContext` / `mapProps` / `fieldsMap` 等 React 工具
  - 入口：[Tools 总览](./tools)
- **storage**：`createStorage` / `createStorageHelper` / `createCookieStorage`
- **rq**：`RequestBuilder` / `createApi`（TanStack Query 封装，支持 RSC）
- **store**：`createStore` / `snapshot`（valtio 封装）
- **numbro**：精确数值计算与格式化
- **shared**：共享 hook 与类型工具
- **Agent Skill**：为使用 `@dune2/tools` 的项目提供 Coding Agent 使用指南，帮助 Agent 优先复用已有 API
  - 入口：[Agent Skill](./tools/agent-skill)

### CLI

命令行工具（`@dune2/cli`），从 Swagger/OpenAPI 规范自动生成类型安全的 API 客户端代码。

- 入口：[CLI](./cli)

### Babel

编译时优化插件（`@dune2/babel`），自动将 `store.useSnapshot()` 转换为性能更优的 `store.useShallowSnapshot(selector)`。

- 入口：[Babel 插件](./babel)
